## ⚙️ Prerequisites

Before you begin, make sure you have the following:

- ✅ **XAMPP** — for PHP and Apache local server  
  👉 [Download XAMPP](https://www.apachefriends.org/)
- ✅ **Git** — for cloning the repository  
  👉 [Download Git](https://git-scm.com/)
- ✅ **A modern browser** — Chrome, Firefox, Brave, or Edge

---

## 🚀 Step-by-Step Setup Guide

### Step 1 — Clone the Repository

Open a terminal or Git Bash and run:

```bash
git clone https://github.com/HelloWorld-Farhan/FAMMED-PROJECT.git
```

---

### Step 2 — Move to XAMPP htdocs

Copy or move the cloned folder into your XAMPP htdocs directory:

```
C:\xampp\htdocs\FAMMED-PROJECT\
```

---

### Step 3 — Start XAMPP

1. Open **XAMPP Control Panel**
2. Start **Apache** module
3. (Optional) Start **MySQL** if database is needed

---

### Step 4 — Open in Browser

Open your browser and go to:

```
http://localhost/FAMMED-PROJECT/index.html
```

Or for PHP version:

```
http://localhost/FAMMED-PROJECT/index.php
```

## 🔧 Troubleshooting

### ❌ Page Not Loading
- Make sure **Apache is running** in XAMPP
- Check the URL: `http://localhost/FAMMED-PROJECT/`

### ❌ Contact Form Not Working
- Make sure **PHP** is enabled in XAMPP
- Open `index.php` instead of `index.html`
- Check `php/` folder for mail configuration

### ❌ Animations Not Playing
- Make sure `gsap.min.js` and `jquery.min.js` are loading
- Check browser console for JS errors (`F12 → Console`)

### ❌ Fonts/Icons Not Showing
- Make sure `webfonts/` folder is present
- Check `all.min.css` is linked in HTML files
